# 关卡数值文档

更新时间：2026-04-14

## 当前关卡列表

### 1. `ruins` 遗迹试炼场
- 标题：遗迹试炼场
- 描述：破碎遗迹中的标准试炼。路线开阔，适合稳定 build 和熟悉节奏。
- 推荐难度：标准
- 地图预览样式：遗迹风格

### 2. `factory` 钢铁工场
- 标题：钢铁工场
- 描述：密集轨道与狭长通路更容易形成压迫，适合测试刷怪强度和机动性。
- 推荐难度：进阶
- 地图预览样式：工场风格

### 3. `sanctum` 星环圣所
- 标题：星环圣所
- 描述：中央高压区域更考验走位和爆发输出，适合后期 build 检查。
- 推荐难度：高压
- 地图预览样式：圣所风格

## 当前实际战斗数值

注意：
- 目前 `3` 个关卡已经接入主菜单选关和地图预览
- 但战斗内数值还没有按关卡拆分
- 也就是说，现在这 `3` 个关卡共用同一套战斗参数

### 对局总时长
- 目标时长：`120s`

### 波次配置
- 最终波次：`5`
- 普通波敌人数：`[16, 26, 38, 52]`
- 普通波刷怪间隔：`[0.50, 0.34, 0.24, 0.17]`
- 第 `3` 波开始出现精英
- 第 `5` 波进入 Boss 波

### 精英数量
- 第 `1` 波：`0`
- 第 `2` 波：`0`
- 第 `3` 波：`1`
- 第 `4` 波：`2`
- 第 `5` 波：Boss 波

### 刷怪位置
- 刷怪距离玩家：`520`
- 从上下左右四个方向外侧刷入

### 波次成长
- 每波生命成长：`+12%`
- 每波移速成长：`+3%`
- 第 `4` 波开始，接触伤害额外 `+1`

## Boss 波当前规则

### Boss 出场
- 进入最终波时刷 Boss
- Boss 出场时额外带 `2` 个小怪

### Boss 战表现
- Boss 专属血条
- 登场字幕
- 蓄力预警圈
- 范围爆发 + 环形弹幕
